MLS Physical Performance Analysis
A Python analysis notebook for exploring Major League Soccer player physical metrics using SkillCorner tracking data from 2023-2025 seasons.
Features

Data Processing: Loads and processes SkillCorner CSV data with 83 performance metrics
Player Analysis: Individual player performance tracking across multiple matches
Speed Benchmarking: PSV-99 (peak sprint velocity) comparisons by position
Position Rankings: Player rankings within their positional groups
Metric Selection: Filters key physical metrics (distance, speed zones, accelerations)

Key Metrics Analyzed

Distance covered, running distance, HSR (High-Speed Running)
Sprint counts and distances
Acceleration/deceleration profiles
Time to reach speed thresholds
Per-90-minute normalized statistics

Outputs

Individual player CSV exports (e.g., yoshida.csv)
Position-based speed rankings and percentiles
Comparative analysis visualizations
Player performance profiles across 30 MLS teams

SkillCorner match tracking data covering full MLS seasons with detailed physical performance metrics.RetryClaude can make mistakes. Please double-check responses.
